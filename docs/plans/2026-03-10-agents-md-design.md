# AGENTS.md Design

## Goal

Create a root `AGENTS.md` that helps coding agents work effectively in this repository.

## Scope

This document is a collaboration guide, not a full architecture manual. It should:

- explain the project shape in a few lines
- map common tasks to the files and packages they usually touch
- state repository-specific working rules
- define the minimum verification expected before claiming completion
- link to `docs/AI_CONTEXT.md` for deeper project background

## Chosen Approach

Use a hybrid execution-oriented guide:

- keep the file short enough for first-read usability
- include task-to-file navigation for common changes
- avoid copying the detailed architecture content already present in `docs/AI_CONTEXT.md`

## Content Structure

1. Project snapshot
2. Code navigation by task type
3. Repository working rules
4. Validation commands
5. Documentation sync rules
6. Common gotchas

## Non-Goals

- duplicate the full contents of `docs/AI_CONTEXT.md`
- provide end-user setup tutorials
- document every platform or agent implementation in detail
